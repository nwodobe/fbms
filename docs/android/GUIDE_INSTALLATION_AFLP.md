# Guide d'installation — ANAGROCI FIELD BUYING (Android)

**AFLP 2027 | Field Operations** · pour les Unit Heads, Assistants, Zonal Heads et RT

---

## 1. Recevoir l'application

Le fichier s'appelle **`ANAGROCI_FIELD_BUYING_AFLP_2027_v1.0.0.apk`** (le numéro change à
chaque nouvelle version). Vous le recevez **uniquement** par le canal officiel indiqué par
le Branch Manager (groupe WhatsApp interne AFLP ou lien de partage interne).

> ⚠ N'installez jamais un fichier APK reçu d'une autre personne ou d'un autre groupe,
> même s'il porte le même nom. En cas de doute, demandez l'empreinte de contrôle
> (code SHA-256) au Branch Manager avant d'installer.

## 2. Installer

1. Touchez le fichier `.apk` reçu (dans WhatsApp : ouvrez le document ; sinon dans *Fichiers › Téléchargements*).
2. Android affiche « Pour votre sécurité, l'installation d'applications inconnues est bloquée » :
   touchez **Paramètres**, puis activez **Autoriser cette source** pour **cette application seulement**
   (WhatsApp ou Fichiers). N'activez pas d'autre source.
3. Revenez en arrière, touchez **Installer**.
4. Si *Google Play Protect* affiche « Application non vérifiée », touchez **Plus de détails › Installer quand même**
   (l'application est interne à ANAGROCI, elle n'est pas sur le Play Store).
5. Une fois installée, **désactivez à nouveau** l'autorisation d'installation pour WhatsApp / Fichiers.

L'icône **ANAGROCI FIELD BUYING** (logo vert et orange, mention AFLP) apparaît sur l'écran d'accueil.

> Une icône **« ANAGROCI FB TEST »** est une version d'essai : ne l'utilisez pas pour le vrai
> travail de terrain.

## 3. Première ouverture et connexion (avec Internet)

1. Ouvrez l'application **avec Internet** (données mobiles ou Wi-Fi).
2. Saisissez l'**email** et le **mot de passe personnels** remis par le Branch Manager.
   Ne prêtez jamais votre compte : chaque opération est enregistrée à votre nom.
3. Messages possibles :

| Message | Que faire |
|---|---|
| Email ou mot de passe incorrect. | Vérifiez l'orthographe de l'email et le mot de passe ; sinon contactez le Branch Manager |
| Pas de connexion Internet… | Mettez-vous dans une zone couverte et réessayez |
| Hors ligne : une connexion Internet est nécessaire… | La toute première connexion exige Internet |
| Compte désactivé. | Contactez le Branch Manager |
| Profil introuvable. | Votre compte existe mais n'est pas configuré : contactez le Branch Manager |
| Accès non autorisé | Votre rôle n'ouvre pas ce module |
| Session expirée… | Reconnectez-vous ; vos opérations restent sur le téléphone |

4. Si l'application demande la **position GPS**, touchez **Autoriser** (« Pendant l'utilisation de l'application »).
   Le GPS sert aux parcelles ; refuser n'empêche jamais un achat.

## 4. Préparer le téléphone avant de partir au village

**Chaque matin, avec Internet :**

1. Ouvrez la rubrique **Synchronisation**.
2. Touchez **Préparer le mode hors ligne** et attendez **« Prêt pour le terrain »**.
3. Vérifiez le nombre de villages, RT et producteurs affiché.

Le téléphone garde alors les données de votre périmètre et vous pouvez travailler sans réseau.
L'autorisation de caisse hors ligne d'un RT est valable un temps limité (affiché à l'écran) :
préparez à nouveau le téléphone chaque jour.

## 5. Travailler sans Internet

- Enrôlements, achats, sacs et GPS se saisissent normalement. L'écran indique
  **« Sauvegardé sur cet appareil »** : l'opération est en sécurité dans le téléphone.
- Le Farmer ID définitif est attribué **à la synchronisation**.
- Vous pouvez fermer l'application ou éteindre le téléphone : rien n'est perdu.
- Ne videz **jamais** les données de l'application (*Paramètres › Applications › Stockage › Effacer les données*).

## 6. Synchroniser

Dès que le réseau revient, la synchronisation part toute seule. Pour vérifier :

1. Rubrique **Synchronisation** : le compteur « en attente » doit revenir à **0**.
2. Une ligne **en échec** ou **à revoir** reste affichée avec son motif : touchez **Réessayer**,
   sinon signalez-la (voir §9). Elle n'est jamais supprimée automatiquement.

## 7. Changer de téléphone ou passer de la version Web à l'application

Les opérations non synchronisées restent **dans le téléphone (ou le navigateur) où elles ont été saisies**.
Elles **ne passent pas** automatiquement d'un navigateur Chrome à l'application, ni d'un téléphone à un autre.

**Avant tout changement** : synchronisez jusqu'à **0 en attente** sur l'ancien appareil / dans Chrome,
puis installez et connectez-vous sur le nouveau.

## 8. Mettre à jour l'application

1. Le Branch Manager envoie la nouvelle version par le canal officiel.
2. **Synchronisez d'abord** (0 en attente) — par précaution.
3. Touchez le nouveau fichier `.apk` puis **Mettre à jour**. **Ne désinstallez pas** l'ancienne version :
   la mise à jour conserve vos données et votre connexion.
4. Si Android affiche « Application non installée » ou « conflit de package », **ne désinstallez pas** :
   prévenez le Branch Manager (le fichier n'a pas la bonne signature).

## 9. Signaler un problème

Envoyez au Branch Manager (ou au Field Buying Coordinator) :

- votre nom et votre rôle ;
- la version de l'application (*Paramètres › Applications › ANAGROCI FIELD BUYING*) ;
- le modèle du téléphone ;
- l'heure, la rubrique, ce que vous faisiez ;
- une **capture d'écran** du message.

N'envoyez jamais votre mot de passe. Ne transférez pas de captures contenant les données
personnelles des producteurs en dehors du groupe interne.
