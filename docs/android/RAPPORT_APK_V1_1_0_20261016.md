Date : 16 octobre 2026 · Branche : `android/aflp-2027-apk-v2` (base : `android/aflp-2027-apk` + `main` eb7d466, PR #260 et #261)

## 2. Ce qui a été fait

1. **Fusion de `main`** dans la branche Android : le paquet embarqué contient l'enrôlement cloisonné
   et le correctif hors ligne (vérifié dans l'APK : `field-buying.js?v=20261016-android-uh-1`, 5 occurrences
   de `ROLES_CLUSTER_TERRAIN` / `withClusterRef`).
2. **Option C hybride** : `WebBundleUpdater.java` (README Android §7). Base embarquée, mises à jour
   depuis une seule source HTTPS approuvée, **signature ECDSA P-256 + SHA-256 par fichier**, anti-rejeu,
   activation au démarrage suivant, différée si le format de la file locale change et que des opérations
   attendent, retour automatique si la version ne confirme pas son démarrage en 60 s. Aucun code distant
   non vérifié n'est exécuté ; le Java, le pont natif et les bibliothèques ne sont jamais remplacés par ce canal.
3. **Scripts** : `sign-web-bundle.mjs` (création de clé hors dépôt, signature, contrôle `--verify`),
   `web-bundle-lib.mjs` (règles partagées), `prepare-web.mjs` (empreintes, numéro de version, configuration),
   `build-apk-local.sh` (prise en charge de `dalvik-exchange`).
4. **Écran « À propos · Version · Synchronisation »** (bouton en bas à gauche) : version, identifiant,
   empreinte du certificat, version Web active, état et motifs des mises à jour, file locale, avertissement
   « Ne désinstallez pas ».
5. **Version** : 1.1.0 / versionCode 2 / `webUpdateMinVersionCode=2`. `applicationId` inchangé.
