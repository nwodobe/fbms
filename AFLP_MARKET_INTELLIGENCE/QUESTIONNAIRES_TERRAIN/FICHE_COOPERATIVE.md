# Fiche C · Coopérative ou groupement

Version du référentiel : 1.0.0. Utilisable sur papier (fiche imprimable `QUESTIONNAIRES_TERRAIN.pdf`, produite par le générateur) et, plus tard, dans FBMS : mêmes codes.

**Consigne.** Entretien avec un responsable volontaire. Aucun document confidentiel n'est demandé ni accepté.

**En-tête à remplir à chaque fiche** : date, heure, cluster, village, panel (FIXE / TOURNANT / HORS PANEL), type d'acteur, code agent, date du fait rapporté si différente, refus OUI/NON.

**Source de chaque réponse** : V = vu par l'agent · R = reçu ou preuve (photo de reçu, document) · D = dit par la personne · I = entendu dire (information indirecte).

| Code | Module | Cat. | Question | Réponse attendue | Unité |
|---|---|---|---|---|---|
| `C01_ACTIVITE` | M04 | B | La coopérative a-t-elle commencé à collecter cette saison ? | OUI / NON / PRÉPARATION |  |
| `C02_VOLUME_DECLARE` | M04 | B | Volume collecté déclaré publiquement ou documenté ? | kg + nature | kg |
| `C03_PRIX_MEMBRES` | M02 | B | Prix payé aux membres (s'il est communiqué) ? | FCFA/kg | FCFA/kg |
| `C04_FINANCEMENT` | M04 | B | La coopérative dispose-t-elle de fonds pour acheter ? (oui / non / ne dit pas) | OUI / NON / NE DIT PAS |  |
| `C05_SACS_MAGASIN` | M04 | B | Sacs et magasin disponibles ? | OUI / NON / INSUFFISANT |  |
| `C06_VENTES_GROUPEES` | M01 | B | Participation à des ventes groupées ou opérations CCAK ? | texte court |  |
| `C07_DIFFICULTES` | M04 | B | Principale difficulté de la saison ? | texte court |  |

Règles : noter le montant et l'unité tels que dits (ex. 20 000 F le sac de 80 kg) ; préciser prix demandé, proposé ou payé ; une quantité dite n'est pas une quantité vue ; aucun nom, aucun téléphone ; un refus est respecté et noté.
