# AFLP FIELD PROOF — guide de l'agent

## Avant de partir (au bureau, avec réseau)

1. Ouvrez FBMS, connectez-vous, touchez la carte **AFLP FIELD PROOF**.
2. Sur iPhone : Safari → Partager → **Sur l'écran d'accueil** (évite que le téléphone efface les fichiers).
3. Vérifiez « Préparation du téléphone » : villages disponibles, caméra, vidéo, espace (300 Mo libres au minimum).
4. Acceptez **Caméra**, **Micro** et **Localisation** quand le téléphone le demande.
5. Chargez la batterie.

## Sur le terrain (sans réseau)

1. **Nouvelle mission** : choisissez le cluster, le village, l'activité. Commentaire facultatif.
   Les informations seront inscrites sur chaque photo et vidéo : vérifiez-les avant de créer.
2. **📷 Prendre photo** : attendez « GPS ±… m » en haut à droite (quelques secondes dehors), visez, appuyez sur
   le rond vert. Vérifiez l'aperçu : **Reprendre** ou **Valider et enregistrer**.
3. **🎥 Enregistrer vidéo** : appuyez sur le rond rouge pour démarrer, de nouveau pour arrêter. Visionnez,
   puis **Recommencer** ou **Valider**. Gardez l'écran allumé : verrouiller le téléphone arrête la vidéo (la
   partie filmée est gardée). Durée conseillée : **2 minutes** ; plusieurs séquences courtes valent mieux
   qu'une longue.
4. Passez librement de PHOTO à VIDÉO : la mission reste la même.
5. Sans GPS : vous pouvez photographier quand même ; le fichier portera **LOCALISATION NON VÉRIFIÉE**.

## Nom du lieu sur la photo

La dernière ligne du bandeau indique la **localité** : nom du village FBMS le plus proche (sans réseau) ou nom
OpenStreetMap (avec réseau). Si vous êtes à plus de 5 km du village choisi pour la mission, elle affiche
**ÉCART** : vérifiez que vous avez choisi le bon village. Avec réseau, seule votre position est envoyée à
OpenStreetMap pour trouver ce nom ; vous pouvez couper cette recherche sur l'accueil.

## Mettre dans la galerie

- **Automatique** : dès « Valider », le fichier part vers la galerie (réglage sur l'accueil, actif par défaut).
- Sinon, ou pour un ancien média : **Enregistrer dans la galerie**.
  - Android : le fichier va dans **Téléchargements** ; il apparaît dans Galerie / Google Photos (album
    « Download »).
  - iPhone : choisissez **Enregistrer l'image** ou **Enregistrer la vidéo** dans la fenêtre qui s'ouvre.
- Ouvrez votre galerie, vérifiez la présence du fichier et du bandeau, puis revenez confirmer
  **« Oui, c'est dans ma galerie »**. L'application ne peut pas le vérifier toute seule.

## Envoyer

- **Partager** (un fichier, ou cochez-en plusieurs) → WhatsApp.
- Pour une preuve **vérifiable**, dans WhatsApp choisissez **📎 → Document**. Envoyée « en photo / vidéo »,
  WhatsApp la recompresse : le bandeau reste lisible, mais le contrôle d'empreinte ne fonctionnera plus.
- **Exporter le dossier (ZIP)** : toutes les photos et vidéos + le manifeste. Fonctionne sans réseau ;
  envoyez le ZIP dès que le réseau revient. Un gros dossier est découpé en plusieurs lots.

## Les personnes que vous photographiez ou filmez

Annoncez le but (dossier de mission AFLP), respectez tout refus, ne filmez pas d'enfant sans l'accord d'un
parent présent, n'utilisez pas les images hors du cadre ANAGROCI.

## Si quelque chose ne va pas

| Message | Que faire |
|---|---|
| Accès à la caméra refusé | Réglages du navigateur → autoriser la caméra pour FBMS, puis réessayer |
| Micro indisponible — vidéo MUETTE | Autorisez le micro si le son est nécessaire, sinon continuez |
| Stockage presque épuisé | Validez la séquence conservée, exportez puis libérez de la place |
| Enregistrement vidéo interrompu (accueil) | Touchez **Récupérer** : la vidéo revient dans sa mission |
| Villages non préparés | Reconnectez-vous une fois au réseau et touchez **Mettre à jour les villages** |

## Pour les responsables

**Accueil → Contrôler un dossier reçu** : choisissez le ZIP (ou les fichiers + `manifeste.json`). Chaque
fichier apparaît **Conforme** (identique à celui produit par l'agent), **Modifié**, **Absent** ou **Hors
manifeste**. « Conforme » ne certifie ni l'heure ni le lieu, qui viennent du téléphone de l'agent.
