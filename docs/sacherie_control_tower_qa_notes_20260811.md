# Notes QA — Control Tower Sacherie

Le contrôle fonctionnel doit privilégier la conservation comptable :

- les transferts changent la localisation, pas le total ;
- les changements d'état changent l'état, pas le total ;
- le REBUT reste un actif physique jusqu'à sortie officielle ;
- la perte approuvée est le seul flux de ce périmètre qui diminue le patrimoine sans destination ;
- les écarts physiques restent visibles et ne sont jamais corrigés automatiquement.

Le défaut de multiplication du stock RT identifié pendant la recette a été corrigé avant intégration frontend.
