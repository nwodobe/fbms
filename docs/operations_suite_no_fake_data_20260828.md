# Production data note

The Operations Suite migrations applied on 2026-08-28 created referential configuration only (canonical sites, warehouses and bag-account locations). They did **not** create synthetic purchases, farmers, LBA financings, deliveries, stock transfers, funding cycles, bag requests, AFLP envelopes or factory process transactions.

The 15,000-bag AFLP envelope shown in the design specification remains an example and was not inserted into production.
