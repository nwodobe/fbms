# Farmer Registry complet — Release du 18 août 2026

Cette livraison intègre dans FBMS :

- le Farmer Passport 360° ;
- les parcelles multiples et le GPS Level 1 ;
- les baselines Production et Sustainability ;
- 25 critères Sustainability versionnés ;
- les inspections, visites et actions correctives ;
- les preuves privées ;
- les indicateurs de complétude, maturité et risque ;
- le fonctionnement offline et la synchronisation contrôlée.

La base Supabase a reçu les migrations additives documentées dans `farmer_passport_migrations.md`. Les contrôles serveur ont été exécutés dans des transactions annulées, sans conserver de données synthétiques.
