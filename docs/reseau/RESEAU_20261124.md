## E. Guide court pour les agents

- **Créer un village ou un RT** : Modules → Réseau → « Créer : village, RT, producteur », puis
  « + Nouveau village » ou « + Nouveau RT ». Les mêmes boutons sont en tête de « Rechercher »,
  « Villages » et « RT ». Il faut une **connexion Internet** pour enregistrer : hors ligne, le formulaire
  le dit et n'enregistre rien.
- **Rechercher** : Modules → Réseau → « Rechercher ». Tapez un nom même partiel (accents et
  apostrophes inutiles : « nguessankro »), un code RT, un Farmer ID ou un téléphone.
- **Filtrer** : boutons Types (Clusters, Villages, RT, Producteurs) et Clusters — plusieurs à la fois ;
  puis Village et RT. « Producteurs sans RT » montre les fiches non rattachées.
- **Retirer un filtre** : appuyez sur sa pastille « … × » sous les filtres, ou sur « Réinitialiser ».
- **Données limitées au téléphone** : hors ligne, un bandeau orange indique « Recherche dans les
  données disponibles sur cet appareil » ; une fiche absente peut exister dans FBMS.
- **Carte** : Modules → Réseau → « Carte des villages » ; « Trouver un village sur la carte », ou
  « Voir sur la carte » depuis un résultat ou une fiche village.
