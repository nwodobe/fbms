# Operations Suite — known gaps after P0 architecture implementation

The following items are intentionally not hard-coded because the approved specification marks them as requiring business/SOP validation or historical-data reconciliation.

- Funding Exposure accounting formula — Finance sign-off required.
- Financial Balance sign convention — Finance sign-off required.
- RCN Balance calculation convention — Procurement/Finance sign-off required.
- Aging, low-coverage and funding-without-delivery numeric thresholds — configurable values to be approved.
- Transfer weight/quality variance tolerance — QA/Operations sign-off required.
- AFLP campaign bag-envelope quantity — no 15,000 seed was inserted; the figure in the design document is an example.
- Historical 2026 workbook migration — requires staging, row provenance and reconciliation before production import.
- Full legacy-screen replacement — stable RCN TRACE/Field Buying screens are currently reused behind the new information architecture.
- Expanded Factory cooking/shelling/kernel stages — outside P0 until SOPs are validated.
- Physical field pilot — not executed by this software change.
