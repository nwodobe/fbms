Créer un accès

Le compte d'authentification est créé côté serveur, puis le profil (rôle, affectation, statut) est enregistré avec vos droits de Branch Manager : les règles serveur (rôles reconnus, cluster valide, journal des habilitations) s'appliquent à la création comme à la modification.

Comptes et rôles

Les rôles proposés sont ceux que le serveur reconnaît et que vous pouvez attribuer. La valeur enregistrée est la valeur canonique du serveur ; le libellé n'est qu'un affichage. Un poste limité à un cluster (Chef d'Unité, Magasinier) ne peut rien mouvementer tant que son cluster n'est pas renseigné.
